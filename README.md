# Orientation Field Notes

刘璨玮的香港中文大学（深圳）会计分析 Orientation 个人分享网站。

公开访问：[https://assahhi.github.io/asahi.github.io/](https://assahhi.github.io/asahi.github.io/)

## 本地开发

```bash
npm install
npm run dev
```

## 更新 GitHub Pages

```bash
npm run build:pages
```

GitHub Pages 从 `main` 分支的 `/docs` 目录发布。
